# 匿名双眼图像示例

10名患者、20张原始彩色眼底图像，分辨率均为512×512；非弱视和单眼弱视各5名。公开发布授权由数据提供者确认。文件名与图像元数据不含患者姓名、就诊日期或原始编号；图像诊断内容未被修改。

`labels.csv`中：`patient_id`为发布专用匿名编号；`label=0`为非弱视，`label=1`为单眼弱视；`right_image`为右眼，`left_image`为左眼，路径相对此目录。标签沿用原始记录，不根据图像重新诊断。

这些病例选自本次seed42历史测试集，仅供验证数据格式和离线推理。它们不是训练集，也不是新的独立验证集，不能将这10例的结果替代完整测试集指标，或据其表现调整模型后继续声称独立测试。

从仓库根目录运行：

```bash
python demo.py
python predict.py --classifier logistic --right sample_dataset/images/case_001_R.png --left sample_dataset/images/case_001_L.png
```

示例数据仅用于本项目授权的非商业研究演示，不得尝试重新识别患者、关联身份、作临床诊断或擅自扩大授权用途。编码器许可不自动授予额外的临床数据权利。
