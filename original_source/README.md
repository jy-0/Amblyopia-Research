# 完整实验源码留档

`model_code/`保留本次原图实验、编码器提取、队列整理和报告脚本及其本地Python依赖，共23个模块。为保留实验脉络，部分脚本同时含表格、融合或历史任务分支；本次发布的两个权重仅对应1100人队列的原图弱视分支。

`executed_snapshot/`保留本轮实际执行的训练脚本和报告脚本快照。原始脚本中的本地路径、私有清单及临床表格依赖予以保留，不代表这些私有数据一并发布。运行留档脚本需要自行配置路径和合法授权的数据；可选依赖见根目录`requirements-original.txt`。

无需历史数据的独立推理与训练入口位于仓库根目录，其导出分类器和训练实现已与原实验逐项复核。`legacy_source/`另保留本仓库更新前的全部四个Python源文件，未删除旧代码。
